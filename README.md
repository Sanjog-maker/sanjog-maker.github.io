A responsive single-page portfolio built with plain HTML, CSS, and JavaScript and designed for GitHub Pages.

- [ShopIQ](https://github.com/Sanjog-maker/Sanjay-s-shop-webapp) — AI-assisted retail billing and inventory application.
- [ChurnIQ](https://github.com/Sanjog-maker/Sanjay-s-ChurnIQ) — customer churn intelligence and retention workspace.
- [WebScraperIQ](https://github.com/Sanjog-maker/Sanjay-s-WebScraperIQ) — web data extraction and preparation workspace.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**.
4. Save the settings.
5. After GitHub Pages finishes deployment, visit **https://sanjog-maker.github.io**.

## Local preview

Open `index.html` directly in a browser. No package installation or build step is required.
